## Synthetic bench records (tests/fixtures/td5_records.py)

Generated from a known circuit with `core.circuit`, so the identified values can
be compared with the truth. Measured values: U (line), I, P for 8 no-load points
(0,4 … 1,1·Un) and one locked-rotor point at 0,25·Un; DC test U_dc, I_dc at 5 A.

| Case | Circuit | R1 | p_mec | Temperatures |
|------|---------|----|-------|--------------|
| A | TD5 Ex 1 | 0 | 0 (TD5: negligible, given) | — |
| B (démo) | TD5 Ex 1 + synthetic R1 and p_mec | 0,5 Ω at 75 °C | 60 W (separated by the U² fit) | DC test at 20 °C |

Noise: each measured value × (1 + 0,02·N(0, 1)), fixed seed 2026. Temperatures and nameplate are exact.

## data/

Both demo files are generated by `python -m evlab.io.demo_data` (a test checks
they match the generator). Circuit: TD5 Ex 1 (Rf = 230 Ω, Xm = 46 Ω, X = 4 Ω,
R'2 = 2 Ω) plus synthetic R1 = 0,5 Ω at 75 °C and p_mec = 60 W (démo): TD5 Ex 1
has R1 = 0, which would make the DC test read 0 V. Noise: 2,5 % relative
Gaussian on each reading, seed 2026. The reference circuit is stored in the
`# reference.*` header lines.

| File | Content | Columns |
|------|---------|---------|
| `bench_tests_demo.csv` | DC test at 20 °C (5 A), 8 no-load points 0,4…1,1·Un, locked rotor at 0,25·Un, winding at 75 °C | essai (dc / vide / rotor_bloque), U [V] (line; DC: between two terminals), I [A], P [W], f [Hz], T [°C] |
| `load_points_demo.csv` | 12 load points, g = 0,02…0,40 at rated voltage; slip and voltage exact, shaft torque = T_em − p_mec/Ω | g [-], U [V] (line), I [A], T [N·m], cos_phi [-], f [Hz] |

| `cycle_demo.csv` | synthetic urban cycle (not WLTC), 475 s, 3,73 km, v_max 60 km/h (A25) | t [s], v [km/h] |

**Official WLTC files (to be provided by the user, never invented or downloaded):**
`data/wltc_class1.csv` and `data/wltc_class3.csv`, columns `t [s]`, `v [km/h]`
(any sampling; resampled to 1 s). Tests check, when the files are present:
class 3 — 1800 s, 23,27 km ± 0,5 %, v_max 131,3 km/h; class 1 — the first
1022 s (Low + Medium) give 8,091 km ± 0,5 % and 64,4 km/h, and a trailing
phase, if any, repeats the Low phase. Tab 4 uses the file of the vehicle's
class when it exists, else the demo cycle (and says so).

## FEM (data/fem_cache/)

No input file: the FEM geometry is assumption A32 (démo). `data/fem_cache/` holds
runs solved with FEMM 4.2 (written by tab 6 after each complete run), replayed when
FEMM is absent. One folder per case, `<fer>_<Î>A_<N_c>sp_y<y>_<n>im`:
`frame_NNN.png` (|B| maps), `b_r_demo.csv` (`theta [rad]`, then `B_r frame_NNN [T]`
at mid-gap) and `meta.json` (case, frames solved by FEMM, date). Committed:
`m19_7.07A_10sp_y7_12im` (I_µ of TD5 Ex 1) and `m19_18A_10sp_y7_12im`
(overexcitation), each 2 frames solved and 10 derived by symmetry.
